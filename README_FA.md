# عکس‌چین | نسخه پیشرفته ویندوز

## امکانات
- افزودن چندین عکس و حذف عکس‌های انتخابی
- جابه‌جایی ترتیب عکس‌ها
- Drag & Drop برای رها کردن عکس‌ها داخل پنجره (با tkinterdnd2)
- قالب‌های آماده: ۲ و ۳ عکس افقی، ۴ عکس مربعی، ۶ عکس، ۹ عکس و ۴ عکس عمودی
- چیدمان آزاد شبکه‌ای، افقی و عمودی
- تنظیم تعداد ستون‌ها، فاصله و رنگ پس‌زمینه
- دو حالت نمایش کامل یا برش برای پر کردن کادر
- پیش‌نمایش زنده
- خروجی JPG با کیفیت ۹۶ یا PNG
- تنظیم عرض و ارتفاع خروجی تا ۱۲۰۰۰ پیکسل

## نصب و اجرا در ویندوز
1. Python 3.10 یا جدیدتر را نصب کنید.
2. فایل ZIP را استخراج کنید.
3. در پوشه AksChin، PowerShell را باز کنید و اجرا کنید:

```powershell
py -m pip install -r requirements.txt
py akschin.py
```

اگر نصب tkinterdnd2 در سیستم شما ممکن نبود، برنامه همچنان اجرا می‌شود و افزودن عکس با دکمه فعال است؛ فقط Drag & Drop در دسترس نخواهد بود.

## ساخت فایل EXE
برای ساخت فایل اجرایی مستقل، در همان پوشه PowerShell را باز کنید:

```powershell
py -m pip install pyinstaller
py -m PyInstaller --noconfirm --onefile --windowed --name AksChin --collect-all tkinterdnd2 akschin.py
```

فایل نهایی در مسیر `dist\AksChin.exe` ساخته می‌شود. برای ساخت EXE ویندوز، دستورها باید روی ویندوز اجرا شوند.
